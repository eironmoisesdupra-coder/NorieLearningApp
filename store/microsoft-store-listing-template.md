# Microsoft Store listing draft

Unpublished editorial draft. Store identity, certificate, public privacy URL,
support contact, declarations and production package review remain pending.

**Product name:** NorieLearning

**Description draft:**

Explore lessons, practice activities and study tools on your PC. NorieLearning
stores core lessons and progress locally, with Classroom sharing available on a
supported local network. Continue learning offline and revisit earlier work.

Account and connected service availability depend on the deployed build and
configuration. Final copy must describe only functionality verified in the exact
production package. Do not claim production AI/cloud features or deletion and
recovery behavior that have not been tested.

## Required owner and release review

- Choose and validate the Store packaging route and assigned package identity.
- Validate the production certificate, publisher identity, signatures and update path.
- Capture real production screenshots and review final icons and graphics.
- Supply a working public support contact and published privacy policy.
- Complete age/content ratings and privacy/data declarations from actual behavior.
- Review learner privacy, local-network permissions, optional account flows,
  retention and third-party attribution. This template asserts no legal compliance.
- Test installation, launch, offline lessons, accessibility and migration on the
  actual Windows release package, retaining source/build and artifact bindings.

The portable preview ZIP is useful for preview distribution. It does not establish
that a Microsoft Store submission package or production signing is ready.
