# #23 + #26 Rich Lesson Experience and Adaptive Quizzes
Teach through Discover→Understand→Follow→Guided Try→Independent Try→Apply→Review. Early grades 1–3: Norie short explanations, large visual/manipulative count/match/sort, friendly progressive guided play. Grades 4–6: vocab, visual diagrams, multi-step examples. G7–10: concepts, problem solving, common misconceptions and application. G11–12/college: derivations, independent proof/quantitative reasoning, optional scaffolding. Worked solving template: Given/Find/Strategy/Steps/Units/Check or domain-specific. Use worked-example fading. Assessment mix depends on lesson, not always 20 MCQs: concepts, calculation, interpretation, error analysis, multi-select, numeric-with-units, matching, ordering etc. Sample Math: 25% concept,50% solving,15% application,10% error analysis; quantitative science:20/50/20/10. Apply only when solving is relevant. Distinguish completion, assisted practice, independent mastery, later retention; guided help does not reduce credits/XP. Grade-specific editorial and accuracy reviews mandatory.
