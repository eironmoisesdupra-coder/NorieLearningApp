# #22 Curriculum Library
Build reusable concepts/skills/lessons/questions/worked examples/misconceptions/visuals/packs with stable IDs and immutable revisions. Separate authoring library from published curriculum registry. States draft→review→approved→published→retired; only vetted published revisions appear in learners' offline maps. Metadata include objective, subject/grade, unit, prerequisites, reading level, author/reviewer, content source, asset license, quiz-bank refs, revision and progress-compatibility. Adapter must preserve all existing topic IDs and learner evidence. Validate prerequisite DAG, duplicates, answer keys/units, alternatives, accessibility assets, thin explanations and content license. No placeholders passed off as published lessons.
