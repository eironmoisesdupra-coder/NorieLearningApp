# Norie personality and reminders: post-pilot specification only

Tone: curious, playful, warm but not guilt-driven. Norie responds to actual saved state, never invents events or personal facts. Learner can disable every reminder type independently; parental controls and quiet hours take precedence. No notification permissions requested in MVP.

Candidates: unfinished case "Your notes are saved. Want to continue the mystery?"; new optional event "A new investigation is available"; missed streak "A fresh start is fine—your progress is still here." Never use shame, FOMO, urgent scarcity, fabricated emergencies, threats, or repetitive nudges. Avoid sending information about academic weaknesses to lock screens.

Later implementation requires explicit opt-in, age-appropriate defaults, quiet hours, max frequency (e.g. one gentle reminder daily or fewer), scheduled/cancel semantics, privacy evaluation, offline queue handling, actual permission lifecycle and notification QA on devices.
