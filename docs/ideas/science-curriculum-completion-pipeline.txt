==================================================

Every lesson must have its own:

- examples;
- diagrams;
- vocabulary;
- misconceptions;
- practice questions;
- challenge questions;
- visuals;
- difficulty level.

Do NOT simply swap nouns into the same lesson text.

Examples:

A Grade 2 lesson about plants should not be a rewritten copy of Grade 1 Plants & Animals.

A Grade 6 ecosystems lesson should contain more scientific relationships and vocabulary.

A Grade 10 genetics lesson should be substantially deeper.

A Grade 12 or College lesson should use appropriate formal scientific concepts.

3. PROCESS LESSONS INDIVIDUALLY
==================================================

For EACH Science lesson, execute this pipeline:

STEP 1 — Inspect
- grade level;
- lesson title;
- prerequisite lessons;
- nearby topics;
- existing curriculum structure.

STEP 2 — Define learning outcomes
Write 3–5 measurable objectives.

STEP 3 — Author the lesson proper
Create actual study content.

STEP 4 — Plan visuals
Choose meaningful lesson-specific diagrams/images.

STEP 5 — Create quiz
Generate questions based ONLY on concepts actually taught.

STEP 6 — Create mastery challenge
Generate 3 appropriate challenge items.

STEP 7 — Validate factual accuracy
Check definitions, examples, units, terminology, and answer keys.

STEP 8 — Validate grade appropriateness
Check reading level and concept depth.

STEP 9 — Run automated curriculum tests.

STEP 10 — Only then proceed to the next lesson.

Never write all lesson text first and "validate later."

6. QUIZ FORMAT RULES — MANDATORY
==================================================

GRADE 1:
MULTIPLE CHOICE ONLY.

GRADE 2:
MULTIPLE CHOICE ONLY.

GRADE 3 AND ABOVE:
May use:
- multiple choice;
- identification;
- other supported quiz modes where appropriate.

IDENTIFICATION RULE:

Every identification answer MUST be exactly ONE WORD.

Examples:

Photosynthesis
Nucleus
Gravity
Evaporation
Mitosis

NOT allowed:

"solar system"
"cell membrane"
"Newton's law"
"water cycle"
"chemical reaction"

If the academically correct answer requires more than one word:
do NOT use it as identification.

Convert it to multiple choice instead.

Programmatically validate identification answers:
- not empty;
- trimmed;
- contains no spaces/whitespace;
- not a phrase;
- not a sentence.

==================================================
8. QUIZ DOMAIN RULE
==================================================

Every quiz item must test something actually taught in THAT lesson.

Before accepting a question, ask:

"Could a learner answer this question from this lesson?"

If not:
reject it.

Never generate:

"Which study strategy is useful?"

"What is the best way to learn this topic?"

"Why should students pay attention?"

Those are not Science questions.

==================================================
9. SCIENCE QUESTION ACCURACY
==================================================

Every question must have:

- exactly one defensible answer for single-answer MCQ;
- plausible same-domain distractors;
- useful answer explanation;
- no trick wording;
- no ambiguity.

For calculations:
independently calculate the correct result.

For classifications:
verify every option.

For scientific terminology:
use accepted terminology.

For claims with exceptions:
avoid inaccurate absolute wording such as:

"always"
"never"
"all"

unless scientifically justified.

15. SCIENCE SAFETY
==================================================

Any experiment/activity must be age-appropriate and safe.

For younger learners:
avoid hazardous experiments entirely.

When appropriate:
include trusted-adult supervision.

Never instruct children to:
- taste unknown substances;
- smell unknown chemicals closely;
- touch dangerous materials;
- mix unknown chemicals;
- interact unsafely with electricity/fire/heat.

Prefer observation-based activities for younger grades.
