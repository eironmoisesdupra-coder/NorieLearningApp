# Packet 06 ? portable content pack staging

Portable JSON packs are size bounded, versioned and fingerprinted. Canonical SHA-256 fingerprints detect modification; they are not publisher signatures or authorization. Manifests include metadata, localization, asset references and revision snapshots. Imports are parsed and checked entirely before draft staging. Claimed client publication states are never trusted or installed in the learner registry.

Assets must be relative offline assets with accessibility text, license and an available packaged file. The pack format references files; it does not fetch network content, unpack arbitrary archives or install executable content. External files require a future verified asset delivery mechanism. Re-export of an incomplete local draft is permitted with visible validation issues, enabling real authors to exchange work; those warnings never constitute publication approval.

Filipino/AP expansion beyond existing authored coverage requires verified sources, subject-specific teaching content and actual review. This packet provides the safe staging pipeline, not fabricated new lesson banks.

Resource limits also apply to each revision before model construction: 1 MiB, nesting 24, 64 lesson sections, 32 points per section, 128 questions per bank, 16 alternatives, 32 accepted answers/ordered steps, 128 assets, and 64 explicit authored assessment items. Pack nesting is capped at 32 and packs contain at most 128 revisions. This prevents a small but densely structured import from exhausting the preview renderer.
