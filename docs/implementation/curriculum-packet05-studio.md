# Packet 05 ? local curriculum studio and paths

Studio drafts and revision histories are scoped to the active owner key supplied by the application. Anonymous local ownership must use the application's stable local owner identity. These local keys are an organization boundary, not a server authorization mechanism. Switching accounts must rebuild the studio with the new owner key.

Editing creates an immutable history entry; rollback appends a copy of the previous entry instead of deleting history. Validation and preview remain available for incomplete drafts. Search covers ID, title, subject and grade. Exported drafts never become learner content through this studio. Publishing and reviewer signoff require a separately authorized server integration and real editorial evidence.

Paths reference exact ID/revision/fingerprint snapshots. Missing or unvetted references, duplicate nodes, prerequisite omissions, ordering and cycles block a valid path. Existing bundled lessons can be referenced without claiming new editorial approval. Learner topic IDs remain unchanged.
