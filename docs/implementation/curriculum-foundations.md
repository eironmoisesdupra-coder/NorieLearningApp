# Curriculum implementation boundaries

Packets 03–06 extend the bundled authored curriculum without changing lesson IDs, progression, XP, credit or mastery authority. Existing bundled content is identified as existing bundled content, with no fabricated editorial signoff. Imported revisions and local edits always remain staged drafts. Only a future server-authorized publication integration can install vetted content.

Packet 03: immutable content snapshots, canonical SHA-256 fingerprints, existing curriculum adapter, structural/editorial validators. Packet 04: guided reading and multi-format rehearsal, separately labelled assistance evidence; existing rewarded lesson and assessment routes remain authoritative. Packet 05: owner-scoped durable local authoring, revision history, preview/diff/rollback, pinned prerequisite paths. Packet 06: bounded portable JSON packs, fingerprint and offline asset checks, staging only.

Editorial gaps remain visible in validation: objectives, reading level, sources, author/reviewer, content license, complete teaching flow, accessible offline visuals, and grade/subject review require real authoring and review. No new Filipino/AP lessons or generic filler bank is generated by this pipeline.
