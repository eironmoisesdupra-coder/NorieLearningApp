# 0.13 polish and certification

Implemented from the user-supplied 2026-10-17 WIP against develop 6364ff7c043a465653e13cc8108a4be08ee3b312. Version 0.13.0+17 remains Preview.

## Classroom
QR and copied-link entry come first, with explicit Join and accessible manual address/code fallback. Typed transport failures give actionable recovery without diagnosing unknown Wi-Fi/firewall causes. Retrying sends the same locally saved result ID; duplicate acknowledgements say the result was already received. No classroom XP, credits, mastery or league rewards are introduced.

Teachers see current frozen shared assignments, session status, temporary code, Stop, anonymous active device links and submitted-alias counts. Links are random per connection, memory-only, capability-negotiated, bounded to128, heartbeated every20seconds, and expire after60seconds without a heartbeat. Explicit disconnect sends a best-effort leave. A missed leave expires naturally. These are device links, not verified students or attendance. Older0.12 peers remain usable without link tracking. Codes/session identity still rotate on restart and sharing stops on route departure/ownership change.

Use existing device-certification v2 tools on five physical hardware classes. Include a real Windows teacher and two physical Android learners on the same Wi-Fi with internet disabled; QR permission/scan, firewall prompt, disconnect/reconnect, duplicate returns, accessibility, offline restart and unchanged XP/credits. Bind source/version/signed artifact hashes in human-reviewed evidence. Production credentials and real preview-to-production Android migration remain external requirements.

## Store path
Platform CI produces the normal Preview APK/portable Windows ZIP plus a separate Preview AAB artifact. That AAB uses the existing preview/debug signing configuration and is not a production-store candidate. The existing protected production workflow now offers apk/aab selection, validates exact tested AAB provenance, replaces only prior JAR signing entries, checks a pinned real JAR signature and compares every application payload file. It remains candidate-only and has not been run with credentials. Real-key AAB rehearsal, signed Windows Store identity/package review, physical certification and reviewed legal/store declarations remain mandatory pending gates. No store submission or credential creation occurs here.
