# Norie Learning — Product Vision

## Audience

Norie Learning should serve three broad learner groups without feeling like three separate products:

1. Junior and Senior High School
2. College
3. Professional / self-directed learners

## Experience principle

Norie should feel like a **premium learning platform that is genuinely gamified**, not a traditional LMS with points added afterward.

Target balance:

- Professional educational clarity
- High-quality game-like progression
- Rich 3D and subject-specific visual identity
- Fast, readable, responsive interface

## Brand direction

Primary tagline:

**Play · Learn · Grow Further**

Visual language:

- Dark navy / near-black surfaces
- Cyan, indigo, violet, magenta, green, and orange accents
- Subject-specific color identities
- Rounded glossy cards
- Soft glow and depth
- 3D educational objects used selectively
- Strong typography and hierarchy
- Mobile-first responsiveness

## Learning hierarchy

Example:

Science
→ Chemistry
→ Atomic Structure
→ Lesson
→ Quiz
→ Interactive Challenge
→ Results
→ XP / Mastery

The information model must allow deeper specialization without redesigning navigation.

## Initial subjects

### Science

### English

## Professional expansion

Later milestones may add structured tracks for fields such as:

- Medicine
- Engineering
- Law
- Other professional disciplines

Professional tracks should reuse the same core learning system while reducing playful visual intensity where appropriate.
