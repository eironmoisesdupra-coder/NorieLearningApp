NorieLearning for Windows (64-bit)

Extract the entire ZIP to a folder, then double-click NorieLearning.exe.
Keep the other files beside the executable. You can create a shortcut to it.

Built-in lessons, practice, challenges and anatomy run offline immediately.
Progress is saved on this PC for the current Windows user.
AI quiz generation, uploads, account sign-in and cloud sync need internet.
Previously saved AI quizzes can be replayed offline on their owning account.

Third-party license files are included in this folder and the bundled app.
